## Ports
- communication endpoint that maps to specific process or network service
	- you can have multiple services at one IP address
	- to read ports `less /etc/services`

## Firewalls and ufw
- security device that monitors network traffic and decides whether to allow or block specific trafic
- **ufw** - uncomplicated firewall
	- `sudo ufw status`
	- `sudo ufw allow ssh`
	- `sudo ufw allow http`
	- `sudo ufw enable`
- to reject all http `sudo ufw reject http`

## Application updates
- `sudo apt install unattended-upgrades`
- `sudo dpkg-reconfigure --priority=low unattended-upgrades`
	- enable upgrades
