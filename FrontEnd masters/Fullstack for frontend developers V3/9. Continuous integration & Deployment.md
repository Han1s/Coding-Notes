- CI
	- changes are validated and merged back into main branch as often as possible
- CDelivery
	- code changes are automatically built and ready for production
- CDeployment
	- builds are automatically deployed to production environment
- The difference between these two is that in delivery we deploy to production manually, in deployment it gets deployed automatically, testing is the main thing in CI/CD


### Spinnaker
- CD for enterprise, overkill for personal projects

## Cron
- executes command on a schedule
- every shell script has to start with 
```bash
#! <location of bash, can find out by command which bash>
<commands to run>
```
- `minute hour day month day sh /path/to/script`
- `crontab -e`
