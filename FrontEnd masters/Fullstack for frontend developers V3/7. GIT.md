- you can then connect git repo to the server
- create `.ssh/config` file and paste
	- ```
	Host github.com
	Hostname github.com
	IdentityFile ~/.ssh/gh_key
	  ```
- change permission of config to 600
	- `chmod 600 ~/.ssh/config`
- change permission of gh_key
	- `chmod 600 ~/.ssh/gh_key`
## If you get stuck
- stop a running process
	- `pkill <process>`
- test a ssh connection
	- `ssh -vT git@github.com`
